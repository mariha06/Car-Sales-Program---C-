Car Sales Management System

A console - based car sales management program written in C as my first-ever coding project at university. The project introduced me to programming fundamentals and gave me practical experience building a menu-driven application.

Features
Car purchasing: Select a car model, year and quantity.
Pricing and discounts: Calculates purchase prices and applies age-based or loyalty card discounts.
Additional options: Includes insurance and extended warranty choices.
Payment methods: Supports cash, card and finance selections.
Sales statistics: Records sales details and displays total sales value.
Stock management: Displays available car models and stock quantities.
Customer feedback: Collects customer ratings and written feedback.
File handling: Saves sales records to a CSV file for later use.
Technologies and Concepts
C programming
Functions and arrays
Pointers and memory access
Conditional statements and loops
User input and validation
File handling using CSV files
Basic calculations and sales record management

Project Background
This was my first experience with coding at university, so the program focuses on applying the fundamentals of C to a simple business scenario. Building it helped me understand how different programming concepts work together to create a functional application.
Looking back at the project, I can also identify ways to make it more realistic and reliable. For example, the original version uses a fixed selection of three car models and an initial stock of 1,000 cars per model. For a small dealership, a more realistic starting point could be around 20 cars in total, with stock levels tracked individually for each vehicle.

Potential Improvements
Make stock levels more realistic and update them accurately after each purchase.
Store individual vehicle details, such as registration, mileage, condition and price.
Improve input validation and error handling.
Make sales records load and save consistently between sessions.
Separate vehicle, customer and sales data into clearer structures.
Explore using a database instead of relying only on fixed arrays and a CSV file.

Project Status
This project represents my starting point in software development. It helped me build a foundation in C and gave me a practical example to reflect on as I develop my programming skills and learn more advanced software engineering concepts.
